DIGITAL SHIELD — учебный MVP
ИИ-проверка подозрительных сообщений и ссылок + помощь живого специалиста.

Что внутри
  index.html        — сайт для клиентов (проверка, помощь специалиста, тарифы)
  expert.html       — рабочее место специалиста (очередь обращений и ответы)
  server.mjs        — сервер на Node.js, без сторонних пакетов
  check.mjs         — ИИ-проверка через Gemini + локальная проверка по казахстанским схемам
  virustotal.mjs    — отчёт VirusTotal по ссылке
  assets/           — котики и иконка
  render.yaml       — настройки для бесплатного хостинга Render

Ключи (оба необязательны)
  Gemini:     https://aistudio.google.com  →  Get API key
  VirusTotal: зарегистрироваться на virustotal.com  →  профиль  →  API key
  Без ключа Gemini сайт всё равно работает: включается локальная проверка по признакам
  (коды из SMS, «служба безопасности банка», поддельные домены Kaspi/Halyk/eGov и т.д.).
  Без ключа VirusTotal просто не будет отчёта по ссылке.
  Ключи НИКОГДА не вписывайте в файлы и не загружайте на GitHub — только в окно запуска или в настройки Render.


1. ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ (проверить, что всё работает)

  1) Установите Node.js 22 или новее: https://nodejs.org (кнопка LTS).
  2) Windows: дважды щёлкните Start-Windows.cmd.
     macOS/Linux: в терминале в этой папке выполните  ./start-mac-linux.sh
  3) Вставьте ключ Gemini и ключ VirusTotal (ввод скрыт) или просто нажмите Enter, чтобы пропустить.
  4) В окне появятся две ссылки:
       Сайт для клиентов:         http://127.0.0.1:8787
       Рабочее место специалиста: http://127.0.0.1:8787/expert#<секретный код>
     Откройте обе в браузере (лучше в двух окнах рядом). Окно с сервером не закрывайте.
     Секретный код меняется при каждом запуске — после перезапуска берите новую ссылку.


2. СЦЕНАРИЙ ДЕМО (для проверки и записи экрана, 1–2 минуты)

  1) Клиент: «Сообщение» → «Пример ↻» (поставщик, скидка 70%) → «Проверить».
     Видно красный вердикт «Высокий риск», объяснение и отчёт VirusTotal. Котик реагирует на вердикт.
  2) Вкладка «Ссылка» → «Пример ↻» (поддельный адрес Kaspi) → «Проверить».
     Для настоящего отчёта VirusTotal вставьте любую реальную ссылку, например https://google.com
     (у выдуманных адресов *.example отчёта в базе нет — это нормально).
  3) Нажмите «Я уже кликнул(а) — нужна помощь», допишите пару слов и «Отправить специалисту».
  4) Окно специалиста: обращение появится само за несколько секунд. Нажмите шаблон (например «Ссылка»)
     или напишите свой ответ → «Отправить ответ».
  5) Окно клиента: ответ специалиста появится сам, ничего нажимать не нужно.
  6) Покажите чек-листы восстановления и прокрутите до тарифов.


3. БЕСПЛАТНЫЙ ХОСТИНГ НА RENDER (публичная ссылка)

  1) Создайте репозиторий на GitHub (можно приватный) и загрузите в него ВСЕ файлы этой папки,
     включая папку assets (на GitHub: Add file → Upload files → перетащить файлы).
  2) Зайдите на https://render.com и войдите через GitHub.
  3) New → Blueprint → выберите репозиторий. Render сам прочитает render.yaml
     и попросит ввести GEMINI_API_KEY и VIRUSTOTAL_API_KEY. Нажмите Apply / Deploy.
     (Если Blueprint не подходит: New → Web Service → репозиторий →
      Language: Node, Build Command: npm install, Start Command: node server.mjs, Instance Type: Free,
      и в Environment добавьте GEMINI_API_KEY, VIRUSTOTAL_API_KEY и STAFF_TOKEN —
      любой длинный пароль из 16+ символов.)
  4) Через пару минут сайт будет доступен по адресу вида  https://digital-shield-xxxx.onrender.com
  5) Ссылка для специалиста:  <адрес сайта>/expert#<STAFF_TOKEN>
     Значение STAFF_TOKEN смотрите в Render → ваш сервис → Environment (или в Logs при запуске).
     Эту ссылку не публикуйте — по ней отвечают клиентам.

  Особенности бесплатного тарифа Render:
   • Если на сайт 15 минут никто не заходит, он «засыпает». Первое открытие после этого
     занимает до минуты. Перед показом или записью демо откройте сайт заранее.
   • При засыпании и перезапуске обращения клиентов стираются (они хранятся в памяти сервера).
     Для MVP это нормально.
   • Если меняете файлы на GitHub, Render сам пересоберёт сайт.

  Если сайт открыт не на Render, а на другом хостинге, задайте переменную PUBLIC_URL
  с адресом сайта (например https://my-site.com) и HOST=0.0.0.0.


Что поменять перед сдачей
  • Цены в блоке «Тарифы» демонстрационные (index.html, ищите «Цены демонстрационные»).
    Поставьте те же цифры, что в бизнес-отчёте.
  • Gemini на бесплатном тарифе: текст может использоваться Google для улучшения сервисов —
    вставляйте только выдуманные примеры. VirusTotal Public API — только для некоммерческого использования.
